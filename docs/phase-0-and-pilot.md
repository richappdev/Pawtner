# Phase 0 — Discovery & compliance checklist

Product gate before Production commerce. Engineering may proceed on Phase 1–4 in Development, but live payments/donation UX require this gate.

- [ ] Confirm operating company / transaction entity
- [ ] Legal + accounting preliminary opinion on MVP payment boundary
- [ ] Interview ≥ 5 private fosters
- [ ] Confirm MVP excludes private cash fundraising
- [ ] Select payment, logistics, e-invoice vendors
- [ ] Counsel confirms no private public-fundraising surface
- [ ] Architecture review scheduled

# Pilot go-live gates (Phase 7)

- [ ] 90% listing completeness
- [ ] Core E2E success ≥ 99%
- [ ] Payment reconciliation delta = 0
- [ ] Critical / High security issues = 0
- [ ] Foster basic listing ≤ 15 minutes
- [ ] AI copy adoption rate ≥ 60%
- [ ] LCP < 2.5s on 75% of key pages
- [ ] API P95 < 500ms (excl. AI / third parties)
- [ ] Search P95 < 1s
- [ ] Uptime target 99.5%
- [ ] Daily backup + documented rollback
